# FestivApp

FestivApp is a white-label mobile app designed for event attendees — whether it's a music festival, a conference, or a workshop.

## Features

- 🗓 **Schedule** – Browse the full timetable, and build your personalized agenda
- ▶ **Live** – See what's happening right now and what's coming up next
- 🗺 **Map** – Navigate the venue with an interactive map
- 💬 **Social** – Share reactions and engage with other attendees
- 🔔 **Updates** – Receive real-time announcements from the organizers

## For organizers

FestivApp is built as a multi-tenant platform. Each event gets its own branded experience (colors, logo, content), managed from a dedicated back-office.
